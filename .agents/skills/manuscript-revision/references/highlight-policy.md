# Highlight Policy

Use these deterministic assignments:

- Reviewer 1: Yellow
- Reviewer 2: Bright Green
- Reviewer 3 and later: assign the next configured palette color
  deterministically by reviewer number; never cap reviewer count at two.
- Shared and general revisions: Violet

A shared change should use Violet unless the author explicitly assigns it to
one reviewer.

Record the assigned category in the single source of truth before applying the
highlight. Apply highlights with a deterministic DOCX processor and verify the
visible color in the rendered manuscript.

Do not use color alone to establish traceability. Link each highlighted change
to its stable reviewer-comment identifier or documented general-revision
record.

The clean revised manuscript must contain the same approved text as the
highlighted manuscript but no revision highlights. Confirm this equivalence
before release.
