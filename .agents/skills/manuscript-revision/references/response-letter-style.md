# Response Letter Style

Create one entry for every inventoried reviewer comment, in source order, using
the stable identifier maintained in the revision workbook or project database.

Use this structure for each entry:

## Reviewer X, Comment Y

### Comment

Reproduce the exact reviewer-comment text.

### Author's response

Respond respectfully, directly, and with evidence. State the interpretation,
decision, and scientific basis without defensive language.

### Changes made in the manuscript

Describe only changes that have been applied and verified in the manuscript.

### Location

Give only a location verified in the applicable rendered manuscript.

### Highlight

Report the verified highlight category from the source of truth.

## Style and integrity requirements

- Preserve exact reviewer-comment text unless encoding artifacts must be fixed.
  If a fix is necessary, document the original text and correction in the
  source of truth.
- Use a professional, appreciative, concise, and non-defensive tone.
- Address the substance of the comment before describing the edit.
- Support scientific explanations with verified manuscript evidence,
  experimental records, or verified references.
- Do not overstate agreement, certainty, novelty, significance, or improvement.
- Do not report a change that is not verified in the manuscript.
- Do not invent page numbers, line numbers, section names, highlights, or
  evidence.
- For an approved rejection or partial response, acknowledge the concern,
  explain the evidence-based reason, describe any verified clarifying change,
  and avoid dismissive language.
- Keep the response, change description, location, highlight, status, and
  evidence exactly consistent with the manuscript and source of truth.
