# HybridQDL Golden Reference

HybridQDL is the acceptance benchmark for workflow and artifact quality, not a
source of scientific wording. Every project must support any reviewer/comment
count and produce an unchanged source, highlighted and equivalent clean
manuscripts, one traceable response per exact comment, a step-by-step Excel
registry, and machine-readable audit records.

Before mutation, the researcher reviews each exact comment with its editable
response and all linked changes. Decisions are bound to hashes of the source,
comment, and complete draft. Shared drafts need approval under every linked
comment; any content change invalidates prior approval.
